# Desafío 7 - FutScript

This is my response to the Desafío 7 - FutScript. It was developed to demonstrate the correct implementation of the following requirements:

- Use JWT to user authorization.
- Use of pg package in a Node Js application.
- Execution of SQL queries to retrieve and insert data from Node.
- Correct use of HTTP codes in the appropriate situations.
- Perform unit tests using the supertest package.

## How to use (Dev Mode)
1. Before anything, to use this app you should have:
    - Postgres installed.
    - Database futscript created.
    - Also, you can run the scripts in [**script.sql**](./script.sql) to setup the database once you have downloaded the repository.

2. Clone, or download the repository.

3. Run the following command in a terminal to install the dependencies:

    ```bash
    $ npm install
    ```

4. Run the tests if you want to check the responses to each route, you can do it with this command:

    ```bash
    $ npm run test
    ```

5. After, start the app with the following command:

    ```bash
    $ npm run dev
    ```

6. Test the routes with Postman, Thunder Client, or any REST API Client that you like.
